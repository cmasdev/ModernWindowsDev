# ModernWindowsDev

A practical exploration of modern Windows development with .NET.

This repository accompanies a series of articles where I build a real
Windows application incrementally using:

- .NET
- C#
- Windows App SDK
- WinUI 3
- XAML

As the project evolves, we'll explore:

- Application architecture
- Dependency Injection
- Configuration
- Local persistence
- Windows APIs
- WSL integration
- Logging and telemetry
- Azure services
- AI integration

## The Project

ModernWindowsDev will evolve into a Developer Companion for Windows:
a native Windows application designed to provide developers with
information and tools related to their local development environment.

The goal isn't to build another collection of isolated samples.

Instead, each article will introduce a concept and apply it to the same
application, allowing the architecture to evolve over time.
